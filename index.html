What this model does

Scientific knowledge is represented as a growing forest of findings. Every step, the field performs exactly one act. With probability r it replicates an existing finding; otherwise (1 - r) it pursues novelty. Novelty either founds a brand-new independent paradigm strand (probability p_new_root) or extends an existing finding. The headline outcome is the precision of the surviving literature: the fraction of published, un-pruned findings that are actually true.

This operationalises March's exploration vs. exploitation and Kuhn's paradigm pluralism as a tunable stochastic process.

Parameters

SymbolRangeMeaning
r0 to 1Probability the next act is a replication rather than novelty.
p_next0 to 1Probability a newly proposed claim (root, or extension of a true base) is actually true.
alpha0 to 1Sensitivity: P(test positive given claim true).
beta0 to 1False-positive rate: P(test positive given claim false).
f0 to 1File-drawer rate: probability that a failed (negative) replication is suppressed and never published. Passed (positive) replications are always published regardless of f.
p_new_root0 to 1Given a novelty act, probability of founding a new independent root instead of extending.

Optimal Replication Rate tab

Every simulation automatically sweeps r from 0 to 1: in steps of 0.01 at the edges (0–5% and 95–100%) and steps of 0.05 in the middle (10–90%). At each step, 100 independent simulations are run (varying only the random seed) and their final precision values are averaged. The bar at the precision-maximising rate is labelled r*. Error bars show one standard deviation across the 100 runs.

Mechanics, step by step

  1. Draw act. With probability r replicate; else pursue novelty. (If no living nodes exist yet, force novelty.)
  2. Novelty to root or extension. With probability p_new_root spawn a new root (parentId = null); its truth is drawn via p_next. Otherwise select a branch via Branch Selection, then a node within that branch via Branch Position (Extension settings).
  3. Inheritance. If the chosen base is false, the extension is necessarily false. If the base is true, the extension is true with probability p_next. Extensions are worthless if the base is false.
  4. Testing and publication. Original studies use false-positive rate alpha_o and false-negative rate beta_o. Failed originals are silently discarded with probability fo; otherwise a faded phantom dot marks the attempt.
  5. Replication and pruning. A replication targets a node selected by the Branch Selection and Branch Position (Replication settings). It is tested with rates alpha_r and beta_r. If positive, the finding is confirmed (solid ring). If negative: suppressed with probability f (dashed ring, finding survives); otherwise published and pruning is attempted with success probability 1 - pruning_resistance. A successful prune removes the node and all descendants recursively (retraction cascade).

Reading the phylogeny

Each dot is a finding; edges link a finding to the parent it extends. Roots (new paradigms) are scattered across the canvas, ringed, and each lineage grows outward in its own random direction, so independent paradigms occupy their own regions. Colour encodes fate: green true positive, red false positive, and grey pruned (refuted by a published replication, along with everything that depended on it). Faded dots are unpublished failed attempts.

Why an interior optimum?

At r = 0 nothing is ever checked, so false positives accumulate and precision collapses. At r = 1 the field only re-checks and never grows, starving the literature. Somewhere in between, replication prunes enough false strands to keep precision high while still permitting growth, the optimal replication rate.
