What this model does

ES-REIn replaces the binary true/false claim of Mono-VEIn with a continuous effect size between 0 and 1, similar to a correlation coefficient (but, for simplicity, always reported as positive). Every finding has a hidden true effect δ, and every study of that finding (its own creating study, or a later verification) produces a noisy observed effect with a 95% confidence interval whose width depends on that study's sample size. Nothing is ever pruned: a small or null observed effect simply stays in the record as a small estimate, rather than being removed.

Generating an effect

A new innovation or extension draws its own true effect δ = U^shape for a fresh uniform draw U; higher shape values concentrate true effects near zero, approximating the typical distribution of correlational effect sizes in the literature. An observed effect is then generated via the Fisher z-transformation: z = atanh(δ) + noise/√(n-3), r = |tanh(z)|, with the 95% CI computed the same way in z-space and back-transformed. Larger sample size n narrows the interval.

Effect-attracted extension

Rather than favouring the newest or oldest finding, an extension's anchor is chosen with probability proportional to (effect size + 0.01)^k: bigger observed effects attract disproportionately more follow-up work, controlled by the Effect Attraction parameter k.

Verification and replicability

A verification draws one more observation of the same finding's true effect, usually with a larger sample size, and is scored as having replicated if the lower bound of its confidence interval exceeds the Detection Threshold, i.e. the interval excludes a null or negligible effect. The estimated replicability rate, the share of all verified findings that replicated by this criterion, is the headline summary statistic, tracked live in Results and swept against the verification rate in the Verification Analysis tab.

Reading the plot

Each dot is a finding, coloured by its own observed effect size from pale grey (near zero) to deep green (near one). A purple ring marks a root strand. A finding that has been verified carries a second ring: green if it replicated, red if it did not. Hover any dot to see its exact effect size, confidence interval, sample size, and (if verified) the same details for its verification.
