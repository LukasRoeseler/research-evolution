What this model does

Bayesian VEIn keeps the Mono-VEIn forest-of-findings structure, but replaces its binary alive/pruned status with a continuous belief: the field's current posterior probability that a finding is true. A failed verification no longer automatically destroys a finding; instead it shifts belief downward by an amount that depends on how strong (informative) that particular verification was. A weak, under-powered failed verification barely dents a well-established finding; a strong one can collapse belief in a shaky finding almost entirely.

Belief updating mechanism

Every finding carries a hidden evidence strength s ∈ (0,1], drawn when it is created (roughly triangular: the average of two independent uniform draws). Belief is tracked in log-odds L = logit(belief). On creation:

CaseInitial belief
New root (innovation)L₀ = s · W
Extension of a parentL₀ = s · W · (ε + (1-ε) · belief(parent))

The leak ε = 0.05 means even extending a nearly-disbelieved parent still gives the child some initial credibility, just much less than extending a well-believed one. Each verification draws its own strength s_ver the same way and, unless filed away, updates belief by L ← L + s_ver · W · (+1 if confirmed, -1 if failed), then belief ← sigmoid(L).

Reading the plot

Each dot is a finding; edges link a finding to the parent it extends. Colour is a continuous interpolation from red (belief near 0) through amber (belief near 0.5) to green (belief near 1). A purple ring marks a root strand. A verification ring is coloured by the direction of its effect and its thickness/opacity scales with that verification's strength, so a faint thin ring is a weak, easily-overturned piece of evidence and a thick solid ring is a strong one. Dashed rings mark filed-away verifications, which left belief unchanged. Faded dots are unpublished failed attempts (the original study never tested positive, so nothing was published).

Why an interior optimum?

At r = 0 nothing is ever checked, so belief in false findings never corrects itself. At r = 1 the field only re-checks and never grows. Somewhere in between, verification pulls belief toward the truth without starving the literature of new findings, the Belief Discrimination Index tab shows where that balance falls for the current parameters.
