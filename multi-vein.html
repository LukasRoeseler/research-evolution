What this model does

Multi-VEIn keeps Mono-VEIn's binary true/false claims and testing mechanics, but replaces its strict tree structure (one parent per finding) with a directed acyclic graph: a finding can depend on several prior findings at once. Each parent link carries a dependence weight between 0 and 1. When a parent is later pruned by a failed, published verification, its dependents are only pruned in turn if their remaining dependence, the sum of weights over parents still alive, drops below a threshold. This lets a finding survive the loss of one weak foundation while still collapsing if it loses enough of its support.

Multi-parent structure

The number of parents an extension depends on is drawn from a chi-square-shaped distribution (via the closed-form Exponential(mean 2) inverse-CDF, scaled by the Fan-in Scale parameter and capped at Max Parents), so most extensions depend on just one or two prior findings with a thin tail of more. Parents are sampled uniformly from all currently alive findings, and each edge is given an independent dependence weight in (0,1]. A finding's hidden truth is true only if all of its parents are true (then re-drawn with the base truth probability); if any parent is false, the extension is false too, generalising Mono-VEIn's inheritance rule.

Cascading pruning

When a verification fails and is published (not filed away, not resisted), the targeted finding is pruned directly. Its descendants are then revisited in creation order: each one's dependence sum is recomputed using only its currently-alive parents, and it is pruned in turn if that sum falls below the Dependence Threshold. Because a finding's dependence sum can only ever decrease over time, this cascade always terminates and is computed correctly in a single forward pass. Worked example: a finding depending on A (0.3), B (0.4), and C (0.3) has dependence sum 1.0. If C is later pruned, 0.7 remains, above a 0.5 threshold, so it survives. If A is pruned too, only 0.4 remains, below the threshold, so it is pruned as a cascade casualty.

Reading the plot

Each dot is a finding; a finding can have multiple parent edges, each drawn with opacity and width proportional to its dependence weight. Colour encodes fate exactly as in Mono-VEIn: green true positive, red false positive, and muted tones for pruned findings (whether pruned directly by their own failed verification, or as a cascade casualty of a parent's pruning).
